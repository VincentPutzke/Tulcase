# Tulcase

Tulcase is a practical VS Code companion for developers who want their support system to live beside the code instead of somewhere else.

It combines task management, notes, saved commands, bookmarks, tags, records, and local database switching in one extension.

## Core Promise

Tulcase should help a developer move faster without creating another system to maintain.

That means:

- short paths to common actions
- low setup friction
- portable local data
- workflows that match real development habits

## What You Can Do

### Track work

- quick-add todos
- review active, upcoming, and done items
- postpone or complete tasks inline
- generate recurring work automatically

### Capture knowledge

- keep project notes in folders
- decorate tags inside note content
- store useful links by topic
- maintain small command libraries for repetitive operations

### Keep operational context close

- log time from inside VS Code
- switch between named databases
- keep personal, project, or client data separated

## Product Direction

Tulcase is not trying to become an all-purpose project management platform.

It is deliberately optimized for the developer sitting inside VS Code who needs:

- a fast scratchpad for commitments
- a durable command memory
- a lightweight notes and references system
- a local history of work done

## Current Modules

| Module | Purpose |
| --- | --- |
| TODOs | Short-cycle execution tracking |
| Notes | Structured lightweight developer notes |
| Commands | Reusable shell and tooling snippets |
| Links | Reference bookmarks with folders |
| Tags | Cross-cutting organization and color coding |
| Records | Time logging and monthly review |
| Databases | Context separation and migration support |

## Practical Philosophy

Tulcase is most useful when it removes repeated micro-friction:

- typing the same shell commands again
- losing project URLs in browser tabs
- storing todos in a tool that is not open during coding
- scattering notes across temporary files and chats

If the tool saves a few seconds many times per day, it earns its place.
